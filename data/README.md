# Data

Download dataset archives from the repository Releases page:

**https://github.com/luwencc/ARISLoc/releases/tag/Data**

Or: repository page → **Releases** → release **Dataset** (tag `Data`).

## Files

- `Trained_Data.tar.zip`
- `Validation_Data.tar.zip`
- `Test_Data.tar.zip`

## Setup

1. Download the archives above.
2. Extract them to get `Trained_Data/`, `Validation_Data/`, and `Test_Data/`.
3. Place the extracted folders (and `ordinate.csv` if included in the release) next to the training scripts, or set paths in `RIS-FLoc/risfloc/config.py`.
